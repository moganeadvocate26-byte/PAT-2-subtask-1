# PAT-2-subtask-1
Morse code is a communication method that transmits text through a standardized series of short and long signals, commonly known as dots and dashes.
Developed in the 1830s and 1840s by Samuel F.B. Morse and Alfred Vail, the system was designed to enable rapid, long-distance communication over telegraph wires. 
Morse was largely motivated to create this technology after a personal tragedy involving his wife’s death, which he learned of too late due to the slow speed of traditional mail.
The system functions by assigning unique sequences of "dits" and "dahs" to letters and numbers, with the dash being three times the length of a dot.
Efficiency is built into the code by assigning the shortest sequences to the most frequently used letters, such as a single dot for the letter "E." This revolutionary system served as the backbone for maritime, military, and international communications for over a century.
